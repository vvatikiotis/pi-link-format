## Behavioral specifications

Keep all behavioral specifications current in the root `SPEC.md`, the single authoritative document. Before discovering, consolidating, or changing behavior, read and follow `.agents/skills/behavior-specification/SKILL.md`. Use Discovery mode for `/grill-with-docs`, Consolidation mode for `/to-spec`, and Reconciliation mode after implementation changes.
