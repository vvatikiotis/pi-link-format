# Issue tracker: GitHub

Task-specific issues and feature-spec snapshots live in GitHub Issues for
vvatikiotis/pi-link-format. Use the gh CLI. The root `SPEC.md` is the single maintained behavioral specification.

- Before publishing or updating a feature spec, follow `.agents/skills/behavior-specification/SKILL.md` in Consolidation mode and update `SPEC.md`.
- Publish the task-specific snapshot as an issue, grouping user stories by complete journeys and including or referencing their acceptance scenarios in `SPEC.md`.
- Read issue descriptions, labels, and comments before acting.
- Use the configured triage labels.

PRs as a request surface: no.
